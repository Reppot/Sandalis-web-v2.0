# Sindaris — персональная установка Windows

Версия 0.1.2 устанавливается без выбора каталога в `D:\Games\Sindaris`. Каждый запуск нового установщика заменяет предыдущую версию в этой же папке. Сначала проверяются доступность диска, право записи и минимум 2 ГБ свободного места на D:.

Основные файлы распаковываются напрямую на D: встроенным несолидным zlib NSIS, без `app-64.7z`, `7z-out` и копии установщика в LocalAppData. Небольшие служебные DLL NSIS могут временно использовать системный Temp. Обычные настройки и сессия приложения сохраняются.

После проверки размеров EXE и app.asar удаляются более старые файлы `Sindaris-Setup-*.exe` рядом с запущенным установщиком. Текущий EXE, версии новее установленной и остальные файлы сохраняются. Чтобы архивы загрузок не копились на C:, сохраняйте и распаковывайте новые ZIP на D:, например в `D:\Games\Sindaris-Updates`.

Это автоматическая установка при запуске нового EXE. Поиск и скачивание новых версий в фоне не включены.

Windows CI устанавливает приложение дважды, сверяет хеши EXE и app.asar, проверяет удаление старых файлов, сохранность пользовательских настроек и отсутствие большого payload в системном Temp.
