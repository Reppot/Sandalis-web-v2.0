## Запуск

Нужны Node.js 22.12+ (либо поддерживаемая более новая версия) и доступ к npm/GitHub для загрузки Electron. Rust, Python, PostgreSQL и Docker пользователю приложения не нужны.

Из корня репозитория в PowerShell:

```powershell
# Пропустить, если зависимости frontend уже установлены.
npm.cmd --prefix frontend ci
npm.cmd --prefix desktop install
npm.cmd --prefix desktop test
npm.cmd --prefix desktop run dev
```

При первом успешном install сохранить созданный `desktop/package-lock.json` в git. В дальнейшем использовать `npm ci`. Lock-файл не изготовлен вручную: в среде разработки 18.11.2026 npm registry недоступен (ENOTFOUND).

```powershell
npm.cmd --prefix desktop run dist:win
```

Ожидаемый результат: `desktop/release/Sindaris-Setup-0.1.0.exe`. Команда создаёт установщик, но не публикует его. Подпись издателя/автообновление не настроены. Не считать exe проверенным или готовым к распространению до реальной сборки и smoke-test.

## Что работает локально по реализации

- Общий интерфейс сайта без отдельной копии JSX.
- Гостевой доступ без серверной авторизации, каталог с фильтрами и пагинацией, рецепты и существующие калькуляторы.
- Ресурсы из backend/static и frontend/public; локальный контент с переводами.
- localStorage интерфейса в отдельном постоянном Electron-профиле. Секреты серверов не включаются в пакет.

Справочники берутся из файлов текущего checkout, а не автоматически из production. Для обновления требуется новая сборка. Локальные данные — JSON-снимок публичных справочников, **не SQLite и не зеркало клановой базы**.

## Авторизация и онлайн-функции

Вход через Discord открывается в отдельном изолированном окне без Node/preload. После штатного callback возвращается локальный интерфейс с состоянием выбора клана; сессия хранится в Chromium cookie-хранилище отдельного partition `persist:sindaris-desktop`.

У запросов API фиксированный сервер. Renderer не получает универсальный IPC/файловые операции, cookies не передаются ему. Redirect в API не выполняются автоматически. Результат ошибки сервера сохраняется как ошибка, а не подменяется успешным кешем.

Совместимость Discord с Electron-окном **ещё не проверена реальным запуском**. При блокировке embedded login потребуется системный браузер и серверный одноразовый обмен, а не ручное копирование токенов. Выбор клана, выход, 401 и повторный вход обязательны для проверки до релиза.

Операции, склады, общие планы, почта и Discord требуют интернета. MapData/текстовый импорт пока используют сервер. Очереди офлайн-изменений, разрешения конфликтов, локальная БД, системные push и автообновление относятся к следующему этапу. Служебный service worker/PWA сайта не включён в Electron.
