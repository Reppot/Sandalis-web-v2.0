# Chronum 0.1.42 — connection recovery and smaller updates

## English

Chronum now allows up to 75 seconds for the first account and clan checks while the API service wakes up. Safe read requests retry after temporary connection resets or server startup responses. Discord sign-in retries temporary connection failures, and overlapping account checks are prevented. If the service is still starting, the companion explains the delay instead of saying the computer is offline.

Desktop and server diagnostics now include a shared request ID, route, status, and timing so a failed client request can be matched to the server log without recording cookies or tokens. Production startup also warns when the JWT signing key is shorter than the algorithm's minimum; it never prints the key.

The installer now keeps one managed copy of the current setup for differential updates. The first update from 0.1.41 may still need the full installer because 0.1.41 did not create this cache. After 0.1.42 is installed, later updates can download only changed blocks. The cache is replaced as updates are installed and removed when Chronum is uninstalled.

For a manual or offline install, download the single full `Chronum-Setup-0.1.42.exe` file.

## Русский

Chronum теперь ждёт ответа API до 75 секунд при первой проверке аккаунта и клана, пока сервис запускается. Безопасные запросы чтения повторяются при временном сбросе соединения или ответе сервера во время запуска. Вход через Discord тоже повторяется после временного сетевого сбоя, а параллельные проверки аккаунта не запускаются. Пока сайт просыпается, компаньон объясняет задержку вместо сообщения, что на компьютере нет интернета.

Диагностика клиента и сервера теперь содержит общий ID запроса, маршрут, статус и время выполнения. Так запрос можно сопоставить с журналом сервера без записи cookie и токенов. При запуске сервер также предупреждает, если ключ подписи JWT короче минимума выбранного алгоритма; сам ключ в журнал не попадает.

Установщик сохраняет одну управляемую копию текущего установщика для дифференциальных обновлений. Первое обновление с 0.1.41 может скачать полный установщик: эта версия ещё не создавала нужный кеш. После установки 0.1.42 следующие обновления смогут загружать только изменившиеся блоки. Кеш заменяется при установке обновлений и удаляется вместе с Chronum.

Для ручной установки или установки без интернета скачайте один полный файл `Chronum-Setup-0.1.42.exe`.
