# Chronum 0.1.40 — connection diagnostics

## English

When a request to the Chronum API fails, the companion now records a rate-limited connectivity check: Windows online status, proxy mode, DNS resolution, and the public API liveness response. This helps distinguish a local DNS or transport problem from an API service issue or a failure limited to one route. The check runs only after a request fails and never uploads a save file.

For a manual or offline install, download the single full `Chronum-Setup-0.1.40.exe` file.

## Русский

При ошибке запроса к API Chronum компаньон теперь выполняет ограниченную по частоте проверку связи: фиксирует состояние сети Windows, тип прокси, результат DNS и ответ публичной проверки доступности API. Это помогает отличить сбой DNS или сетевого соединения от ошибки API либо проблемы только одного маршрута. Проверка запускается только после ошибки запроса и не отправляет файл сохранения.

Для ручной установки или установки без интернета скачайте один полный файл `Chronum-Setup-0.1.40.exe`.
