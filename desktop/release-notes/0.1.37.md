# Chronum 0.1.37 — Windows installer refresh

## English

The Windows setup wizard now carries Chronum's ASCII identity and mascot artwork. It keeps the localized NSIS flow, install-location selection, and per-user or all-users choice.

Installed users can update from the app when GitHub is reachable; the existing NSIS differential download remains enabled. For a manual or offline install, download the single full `Chronum-Setup-0.1.37.exe` file.

## Русский

Мастер установки Windows получил оформление Chronum с ASCII-графикой и маскотом. Сохранились переводы NSIS, выбор папки установки и установка для текущего пользователя или всех пользователей.

Установленную программу можно обновить из приложения, если GitHub доступен; дифференциальная загрузка NSIS остаётся включена. Для ручной установки или установки без интернета скачайте один полный файл `Chronum-Setup-0.1.37.exe`.
