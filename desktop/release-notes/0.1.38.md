# Chronum 0.1.38 — installer refinement

## English

The setup wizard now uses a consistent, readable color scheme across its pages. The welcome page has concise, localized copy; existing installs identify whether Chronum is installed for the current Windows account or for everyone, and confirm that setup will update it. The completion page keeps the optional launch checkbox readable and has one clear final action.

The installer remains available in ten languages, keeps the install scope and folder choices, and preserves differential in-app updates. For a manual or offline install, download the single full `Chronum-Setup-0.1.38.exe` file.

## Русский

Оформление страниц мастера установки стало единым и читаемым. На приветственной странице теперь короткий переводной текст. При найденной установке явно указано, установлена ли Chronum для текущей учётной записи Windows или для всех пользователей, а также что она будет обновлена. На финальной странице читаем чекбокс запуска и оставлено одно основное действие.

В установщике по-прежнему доступны десять языков, выбор типа установки и папки, а встроенное обновление использует дифференциальную загрузку. Для ручной установки или установки без интернета скачайте один полный файл `Chronum-Setup-0.1.38.exe`.
