# Chronum 0.1.39 — sign-in diagnostics

## English

This update improves diagnosis of Discord sign-in and server connection failures. Chronum records request timing, HTTP status, redirect details, and safe network error causes while filtering credentials and personal data. The companion also makes changing the active Discord server easier to find and understand.

For a manual or offline install, download the single full `Chronum-Setup-0.1.39.exe` file.

## Русский

В этой версии улучшена диагностика входа через Discord и ошибок соединения. Chronum записывает длительность запросов, HTTP-статусы, сведения о перенаправлениях и безопасно очищенную причину сетевой ошибки, скрывая учётные данные и личные данные. В компаньоне стало понятнее, как сменить активный сервер Discord.

Для ручной установки или установки без интернета скачайте один полный файл `Chronum-Setup-0.1.39.exe`.
