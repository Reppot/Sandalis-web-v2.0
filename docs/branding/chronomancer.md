# Chronomancer brand

## Identity

- Product: **Chronomancer**.
- Search descriptor: **Foxhole Logi**.
- Search title: **Chronomancer — Foxhole Logi**.
- Mascot: **The Chronomancer**, a hooded keeper with a clock in place of a face.
- Audience: Foxhole players coordinating stockpiles, orders, and production.
- The desktop scanner reads `MapData.sav` on the player's PC. Save data is not uploaded.

## Visual system

- Core palette: coal `#0b090a`, ink `#171213`, oxblood `#51141b`, signal red `#f43f52`, pale text `#fff7f7`.
- Keep the existing self-hosted Inter family for legible interface text; use Russo One only for the wordmark and JetBrains Mono for file paths, game identifiers, and counts.
- The mascot is the signature. Use its existing transparent full-body art in the desktop companion and as a cropped hood-and-clock mark in the website and app chrome.
- Use crimson accents in the standard dark and light themes. Keep success, warning, and danger colors distinct from brand red.
- Retain the existing clan and Discord icons wherever they identify a player's selected server; they are data, not the product logo.
- Preserve local storage keys, Electron origins, auth flows, and install location during the visual rename.

## Search identity

- Page title: `Chronomancer — Foxhole Logi`.
- Describe the website as Foxhole logistics tools and the desktop companion as a local `MapData.sav` stockpile scanner.
- Use structured `SoftwareApplication` metadata and useful page copy; do not rely on `meta keywords` as the SEO strategy.
