# Sindaris Desktop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Создать локальный Windows-клиент, переиспользующий frontend и существующий сервер.

**Architecture:** Electron custom protocol обслуживает локальный Next.js static export и упакованные справочники; остальной API передаётся фиксированному серверу через отдельную cookie-session. Локальный поиск выполняется в worker.

**Tech Stack:** Electron, Next.js, React/TypeScript, Node built-in test/worker_threads, electron-builder.

**Spec:** docs/superpowers/specs/2026-11-18-desktop-design.md

## Global Constraints

- Не менять production/БД и существующий frontend.
- Не хранить секреты в репозитории/renderer и не выдавать браузеру Node/произвольный IPC.
- Офлайн-доступ только к публичным справочникам; клановые записи остаются серверными.

## Review Focus

- Обход путей, percent encoding и посторонние app-хосты должны отклоняться.
- Чужой origin не должен вызывать проксируемые API-мутации.
- Серверные ошибки не должны подменяться успешными ответами.
- Cookies пользователя не должны уходить по redirect стороннему серверу.
- Офлайн-гость не должен сохранять реальные клановые права.
